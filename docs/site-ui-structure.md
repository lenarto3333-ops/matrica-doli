# Матриця долі — затверджена структура сайту та інтерфейсу

## 1. Паспорт документа

| Поле | Значення |
| :--- | :--- |
| Статус | **Збережено та затверджено** |
| Версія | `1.3` |
| Дата фіксації | `04.08.2026` |
| Область | Структура сторінок, компонентів і декоративних елементів |
| Папка документації | `docs/` |

Цей документ фіксує поточну погоджену структуру інтерфейсу. Формули розрахунку описані окремо у `docs/matrix-calculation-standard.md`.

## 2. Маршрути

| Маршрут | Призначення |
| :--- | :--- |
| `/[locale]` | Головна сторінка та форма розрахунку |
| `/[locale]/result` | Результат побудови Матриці долі |
| `/[locale]/account` | Особистий кабінет авторизованого користувача |
| `/[locale]/reset-password` | Відновлення пароля |

Підтримувані локалі визначаються у `src/i18n/config.ts`.

## 3. Головна сторінка

Порядок блоків:

1. `Header` — логотип, навігація, перемикач мови та авторизація.
2. `Hero` — головний заголовок, опис і форма введення дати.
3. `MethodSection` — інформація про метод.
4. `WhatMatrixTellsSection` — можливості матриці.
5. `UniquePersonSection` — текстовий блок і зображення місячної енергії.
6. `EnergiesSection` — опис енергій.
7. `LearnSection` — навчальний та інформаційний блок.
8. `FreeCalculateSection` — повторний заклик до розрахунку.
9. `PricingSection` — тарифи.
10. `ReviewsSection` — відгуки.
11. `FaqSection` — часті запитання.
12. `PromoBlocks` — додаткові пропозиції.
13. `FinalCtaSection` — фінальний заклик до дії.
14. `Footer` — нижня навігація та службова інформація.

## 4. Головний екран

Компонент `Hero` складається з:

- лівої текстової колонки;
- правої картки `CalculatorForm`;
- нижньої смуги переваг;
- фонового шару `MysticBackground`.

`MysticBackground` містить:

- теплий кремово-персиковий градієнт;
- декоративну SVG-схему `HeroMatrixBackdrop` праворуч за калькулятором;
- м’яке радіальне світіння;
- світлу хвилю в нижній частині.

Фонова схема є декоративною та не використовує персональні результати розрахунку.

## 5. Зображення місячної енергії

У блоці `UniquePersonSection` контурний SVG-силует замінено на зображення:

```text
public/lunar-energy-inner-silence.jfif
```

Правила відображення:

- вертикальне співвідношення сторін `2:3`;
- адаптивна ширина;
- повне заповнення контейнера через `object-cover`;
- округлена рамка;
- м’яка бордово-рожева тінь;
- зображення не використовується як іконка профілю.

## 6. Інші сторінки

### 6.1. Сторінка результату

Основні елементи:

- `Header`;
- персональна дата та заголовок;
- `MatrixDiagram`;
- короткі результати;
- блоки призначення, трактувань і тарифів;
- `Footer`.

Фоновий езотеричний декор підключається через `EsotericPageDecor`.

### 6.2. Особистий кабінет

Основні елементи:

- `Header`;
- `AccountSidebar`;
- інформація про збережені матриці та підписки;
- `AccountCards`;
- `Footer`.

Без авторизації маршрут перенаправляє користувача на головну сторінку.

### 6.3. Відновлення пароля

Основні елементи:

- `Header`;
- `ResetPasswordForm`;
- `Footer`;
- спільний фоновий декор `EsotericPageDecor`.

## 7. Єдиний езотеричний стиль

Компонент `EsotericPageDecor` використовується на сторінці результату, в кабінеті та на сторінці відновлення пароля.

Він містить:

- геометричні орбіти;
- місячний знак;
- восьмипроменеву зірку;
- світлові точки;
- м’які аури.

Візуальні правила:

- основний колір — мідно-рожевий `#C87553`;
- низька прозорість;
- символи розташовані переважно праворуч;
- декор знаходиться під контентом;
- декор не перехоплює натискання та не впливає на доступність.

## 9. Розмежування дизайну та розрахунків

- Декоративні SVG-елементи не беруть участі у формулах.
- Зміна фону або зображення не повинна змінювати `src/lib/matrix.ts`.
- `MatrixDiagram` відображає лише значення, отримані від розрахункового модуля.
- Числова структура матриці регулюється документом `matrix-calculation-standard.md`.

## 10. Правила подальших змін

1. Нові сторінки повинні повторно використовувати `Header`, `Footer` і наявні декоративні компоненти.
2. Нові езотеричні символи мають відповідати мідно-рожевій палітрі та тонкому лінійному стилю.
3. Великі фонові зображення зберігаються у папці `public/` з латинськими назвами файлів.
4. Візуальні зміни не повинні погіршувати контраст тексту або роботу мобільної версії.
5. Після структурної зміни цей документ отримує нову версію.

## 11. Палітра виділених слів

Для окремих слів у заголовках і підзаголовках використовується спільний рожево-бордовий градієнт через компонент `AccentWord`.

| Роль | HEX | RGB |
| :--- | :---: | :---: |
| Світлий рожевий початок | `#E48FA1` | `228, 143, 161` |
| Середній рожевий | `#CB7F8F` | `203, 127, 143` |
| Темний рожевий | `#B16F7D` | `177, 111, 125` |
| Бордовий фінал | `#985F6B` | `152, 95, 107` |

Порядок градієнта:

```text
#E48FA1 → #CB7F8F → #B16F7D → #985F6B
```

Палітра призначена для текстових акцентів. Вона не змінює кольори звичайного тексту, фонів і функціональних станів кнопок.
